# 🪨 Rock Paper Scissors Game

A simple, interactive **Rock Paper Scissors** game built with HTML, CSS, and JavaScript. Play against the computer in a best-of-three match and see who wins!

## 🌐 Live Demo

**Play the game online:** [Rock Paper Scissors Game](https://ishan13-dev.github.io/Rock-Paper-Scissors-Game/)

## 🎮 Play the Game

Choose **Rock**, **Paper**, or **Scissors** to play a round against the computer. The game tracks both scores and announces the final result after three rounds.

## ✨ Features

- Play against a computer that randomly selects its move.
- Best-of-three rounds with score tracking.
- Instant round results and final winner announcement.
- Buttons are disabled when the game ends to prevent extra rounds.
- **Play Again** button resets scores and starts a fresh game.
- Responsive layout with a modern glass-style card and gradient background.
- Emoji choices for a fun, simple interface.
- No external libraries or dependencies.

## 🕹️ Rules

- **Rock** beats Scissors.
- **Scissors** beats Paper.
- **Paper** beats Rock.
- Matching choices result in a tie.
- The player with the higher score after three rounds wins. If scores are equal, the game ends in a tie.

## 🖼️ Interface

The game displays:
- Player and computer scoreboards.
- Three choice buttons.
- Round result after each move.
- Game result after round three.
- A Play Again button to restart.

## 🛠️ Built With

- **HTML5** – page structure and game interface.
- **CSS3** – styling, gradients, glass effect, layout, and button transitions.
- **JavaScript (Vanilla)** – game logic, random computer choices, scoring, round management, and DOM updates.

## 🚀 Run Locally

No setup or dependencies are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/Ishan13-dev/Rock-Paper-Scissors-Game.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing!
